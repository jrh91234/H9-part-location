# H9 Part Location

เว็บแอปสำหรับ **โทรศัพท์** (ใช้กับ PDA / หัวสแกนได้ด้วย) ใช้ค้นหาว่า **รหัส Part อยู่ Location ไหน** หรือ **Location นี้เก็บ Part อะไร** บนชั้นวาง H9 (Label / Part ชั้นบน)

- **หน้าเว็บ:** GitHub Pages (HTML/JS ล้วน ไม่ต้อง build ไม่ต้องมี backend)
- **ข้อมูล:** `js/data.js` สร้างจากไฟล์ Excel `Part_Locations_Labels_Upper.xlsx` ด้วย `tools/build-data.py`

---

## การใช้งาน

### 🔎 ค้นหา / สแกน
- **พิมพ์ค้นหา** ได้ทั้ง Location (`L3-05`, `H9-L3-05`, `l3 5`), Child Item Code (`1005QT00456`), Specification (`75503802AA`), ชื่อ Part หรือบางส่วนของคำ (หลายคำได้ เช่น `way 12`) ผลจะขึ้นทันทีระหว่างพิมพ์ คำที่ตรงจะถูกไฮไลต์
- **📷 สแกน** เปิดกล้องหลัง อ่านได้ทั้ง QR, Code128, Code39, EAN-13, DataMatrix มีปุ่ม 🔦 ไฟฉาย / ซูม ถ้าเครื่องรองรับ
  - สแกนป้าย **Location** → แสดง Part ที่อยู่ช่องนั้น
  - สแกนป้าย **Part** (รหัส หรือ Spec) → แสดง Location ตัวใหญ่ + ตำแหน่งบนผังชั้นวาง
  - QR ที่มีข้อมูลหลายช่อง (เช่น `PN:1005QT00456;QTY:100`) แอปจะหารหัสที่อยู่ข้างในให้เอง
  - Spec เดียวกันที่มีหลายรหัส จะแสดงทุกรายการ
  - เสียงสั้นเสียงเดียว + สั่น = พบ · เสียงต่ำสองครั้ง = ไม่พบในรายการ
- **PDA / หัวสแกน Bluetooth (แบบคีย์บอร์ด):** แตะช่องค้นหาแล้วยิงสแกนได้เลย (เครื่องสแกนส่ง Enter ตอนจบ = ถือเป็นการสแกน)
- กรองตาม **Line ผลิต** (4 / 5 / 1) และ **กลุ่ม Part** ได้
- แตะรายการเพื่อดูรายละเอียด คัดลอกรหัส หรือ **🗂 ดูในผัง**
- มีรายการ **สแกน/ค้นหาล่าสุด** 8 รายการ (เก็บในเครื่อง)
- ลิงก์ตรง: `…/#q=L3-05` หรือ `…/#q=1005QT00456`

### 🗂 ผังชั้นวาง
- ภาพรวมชั้น L8 (บน) → L1 (ล่าง) × ช่อง 01–40 สีตาม Line (ส้ม = Line 4 · ฟ้า = Line 5 · เขียว = Line 1) ช่อง 36–40 มีเฉพาะ L1–L5
- เลือกชั้นเพื่อดู Part ทุกช่องในชั้นนั้น แตะช่องเพื่อดูรายละเอียด
- รายการที่ยัง **รอจัดพื้นที่** กดดูได้จากลิงก์ด้านขวา

### อัปเดตอัตโนมัติ
แอปเช็ค `version.json` ทุก 5 นาที และทุกครั้งที่กลับมาเปิดหน้าเว็บ ถ้ามีเวอร์ชันใหม่จะโหลดใหม่เอง (ไม่ต้องล้าง cache)

## อัปเดตข้อมูล (เมื่อย้าย/เพิ่ม/ลบ Part)

ไฟล์ Excel **ไม่ขึ้น GitHub** (อยู่ใน `.gitignore`) ให้วางไว้ที่โฟลเดอร์ repo แล้วรัน:

```bash
pip install openpyxl
python tools/build-data.py            # หรือ python tools/build-data.py path/to/file.xlsx
python tools/bump-version.py
git add js/data.js index.html js/app.js version.json && git commit -m "อัปเดตข้อมูล Location" && git push
```

รูปแบบไฟล์ Excel:
- ชีต **รายการ Part**: `ตำแหน่งที่เสนอ | ชั้น | คอลัมน์ | Line ผลิต | Child Item Code | Specification | Child Item Name | กลุ่ม Part | Data Status | หมายเหตุ`
  - ตำแหน่งที่เขียนไม่มี `H9-` (เช่น `L8-01`) จะถูกเติมเป็น `H9-L8-01` ให้อัตโนมัติ
  - `รอจัดพื้นที่` = ยังไม่มีช่อง
- ชีต **แผนผัง**: ใช้นับจำนวนช่องของแต่ละชั้น (ช่องที่เขียน `ไม่มีช่อง` จะไม่นับ)

## แก้หน้าเว็บ

ไฟล์หลัก: `index.html`, `css/style.css`, `js/app.js` · ทดสอบในเครื่อง: `python -m http.server 8000` แล้วเปิด `http://localhost:8000` (กล้องต้องใช้ https หรือ localhost)

ก่อน push ทุกครั้งให้รัน `python tools/bump-version.py` เพื่อให้เครื่องที่เปิดค้างไว้โหลดเวอร์ชันใหม่
